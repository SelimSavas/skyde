Öne çıkan (highlight) kapakları: düz renk zeminde tek kâğıt kesik ikon, yazısız.

- Sıra: Ada, Defne, Pamuk, Haftalar, Listeler, Gece, Uzman, Topluluk.
- Kapak 1080 × 1080 yüklenir; Instagram daire kırpar, ikon ortadaki %55'te kalır.
- Başlıklar Instagram'da yazılır: kısa ve tek kelime.

Ayrıntılı kurallar: marka kitabı (README) ve Üretim akışı bölümü. Hazır PNG örneği Assets → Sablonlar'dadır.
