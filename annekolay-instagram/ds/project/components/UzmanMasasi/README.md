Uzman Masası carousel kapağı: büyük renkli kâğıt alanında soru başlığı, karakter polaroidi ve uzman damgası.

- Yeni anne versiyonu: üst alan `kil-derin`, yazılar `krem`; alt zemin `seftali`. Hamile versiyonu: üst alan `adacayi-derin`, alt zemin `adacayi-acik`.
- Başlık soru cümlesidir, ikinci yarısı italik.
- `Damga` yalnızca uzman onayından sonra basılır.
- El yazısı not destekleyicidir ("yalnız değilsin."), bilgi vermez.

Ayrıntılı kurallar: marka kitabı (README) ve Üretim akışı bölümü. Hazır PNG örneği Assets → Sablonlar'dadır.
