Ada Sorar, Defne Anlatır Reels kapağı: iki karakter yan yana, altta soru kartı.

- Üst yarı `adacayi-acik`, alt yarı `seftali`, arada yırtık kenar.
- Soru `display-l` krem kartta, ikinci yarısı italik; altında "Defne anlatıyor →" ve bölüm numarası.
- Seri haftada bir, Çarşamba.

Ayrıntılı kurallar: marka kitabı (README) ve Üretim akışı bölümü. Hazır PNG örneği Assets → Sablonlar'dadır.
